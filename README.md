# Deepak Prasad S — Portfolio

Editorial / brutalist-archive portfolio built with React, Vite and TypeScript. Light and dark modes, self-hosted Archivo and Inter, infinite CSS mosaic marquee, magnetic cursor.

```bash
npm install
npm run dev     # local dev server
npm run build   # type-check + production build to dist/
```

Content lives in `src/data/resume.ts`. The résumé PDF is served from `public/Deepak_Prasad_S_Resume.pdf`.
